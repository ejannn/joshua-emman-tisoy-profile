# Joshua Emman Tisoy — Digital Profile

Dark cinematic personal profile website inspired by the supplied reference design.

## Local development

```bash
npm install
npm rundev
```

You can also use:

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Vercel

This is a Vite static site. Upload the project to Vercel or import the Git repository.

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`
